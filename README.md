## Projects

### [DroneCloud](https://github.com/DDD1305/droneCloud)
An experimental C project exploring communication between simulated drones using UDP. Currently a local prototype, with a focus on message parsing and tracking other simulated drones.

### [MasterMind](https://github.com/DDD1305/MasterMind)
A client-server Mastermind game written in C using TCP sockets, with a message protocol and an automated test script.

### [Gradius](https://github.com/DDD1305/Gradius)
A team project developing a Java game.

**My contribution:** Contributed to the Java game engine, including coordinate systems, entity movement, collision detection, and GAL state-machine behaviours. Added unit and integration tests, and implemented ship mechanics such as combined movement and shooting, temporary power-ups, and a dash with cooldown.

### [NIRD-Quest — Nuit de l’Info 2025](https://github.com/Hashemking21/Nuit-info-2025)
A team project building an interactive game to introduce users to Linux, using Vue.

**My contribution:** Developed Vue components for the simulated terminal and narrative text display. Assembled and styled the main game interface, connected player commands to game progression, and integrated the Snake and HorribleInput components into the game flow.

### [STM32 Reflex Game](https://github.com/DDD1305/STM32-reflex-game)

A university project developed in a team of two using C on an STM32F446RE microcontroller. The project consists of a reaction-time game using UART communication, hardware interrupts, SysTick, and a PWM-controlled buzzer.

**My contribution:** Implemented asynchronous UART transmission using interrupts, keyboard input handling, and parts of the game logic, including score management.
